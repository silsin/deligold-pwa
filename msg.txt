feat(market): pull live quotes from the Akbari upstream feed

The board served hand-maintained placeholder numbers, so every price the
UI showed was fake. Now /market/board reads the real upstream feed and
falls back to the static board only when the feed is unusable.

akbari.ts is a standalone, dependency-free client for the upstream
prices endpoint. It POSTs the credentials, tolerates a null `data`
envelope, and maps each row into our internal symbol/quote shape.

Mapping notes, taken from the real payload:

- `price` is per-gram, already in Rials, and can exceed 2^31, so it is
  read as an unnormalised number rather than a normalised float
- `priceBuy`/`priceSell` are 0 for most rows, so buy/sell fall back to
  `price` adjusted by `priceDiff` when the spread is absent
- `ayar` carries the purity (e.g. 750) and is preserved for karat items
- `isActive`/`allowBuy`/`allowSell` gate which symbols are tradeable

When the feed cannot be reached or the token is rejected, the service
logs the reason and returns the last good board flagged `stale` instead
of throwing, so the UI keeps rendering during an upstream outage.

Credentials come from MARK_FEED_URL / MARK_FEED_UID / MARK_FEED_TOKEN
and are never logged. Verified against the live endpoint with the
provided token, and with an expired token to confirm the stale
fallback path.
